\# CodeAlpha Internship Projects

\### Artificial Intelligence | November – December 2026



This repository brings together three projects developed as part of the CodeAlpha Artificial Intelligence Internship. Each project explores a different application of programming, machine learning, and artificial intelligence.



\## Projects



\### 1. LinguaFlow – Language Translation Tool



An interactive language translation application designed to translate text between supported languages.



\*\*Technologies:\*\* Python, JavaScript, HTML, CSS



\*\*Live Demo:\*\* https://linguaflow-codealpha.netlify.app



\### 2. InternGuide AI – Internship FAQ Chatbot



An AI-powered FAQ chatbot designed to help students find information about internships through an interactive question-and-answer interface.



\*\*Technologies:\*\* Python, Flask, NLTK, Scikit-learn, TF-IDF, SQLite, HTML, CSS, JavaScript



\*\*Live Demo:\*\* https://internguide-ai-tv4u.onrender.com



\### 3. MelodyForge AI – Deep Learning-Based Music Generation



An experimental music generation application that uses an LSTM neural network to predict musical note sequences and generate downloadable MIDI files.



\*\*Technologies:\*\* Python, PyTorch, LSTM, ONNX, ONNX Runtime Web, HTML, CSS, JavaScript



\*\*Live Demo:\*\* https://melodyforge-ai.netlify.app
